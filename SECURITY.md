# Security policy

## Supported versions

Security fixes go into the latest major version of `ResponseResultHandler`, `ResponseResultHandler.AspNetCore`
and `ResponseResultHandler.FluentValidation`. Older majors are not patched; upgrade to the latest release.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub instead:
[Security, then "Report a vulnerability"](https://github.com/yahyaerdoan/Response-Utility-Library/security/advisories/new).

Include the affected package and version, what an attacker can do, and the smallest code that shows it. You
will get an answer within 7 days. Once a fix is released, the advisory is published with credit to you,
unless you prefer otherwise.
